# 近接属性

プレイヤーが近接武器で命中させる一次ダメージを2倍にする。個体値・クリティカル・エンチャントの計算後、防御計算前に適用。銃・敵の攻撃・通常のマイクラ武器は変更しない。バニラのスイープ副次ダメージは従来通り。

| 武器 | 効果 |
| --- | --- |
| アーク・ネオンブレード / 雷切・大太刀 | 雷。雑魚20tick、ボス8tickの行動停止。対象ごと60tickの再スタン制限 |
| 紅月・脇差 | 炎。4秒の燃焼＋専用継続ダメージ |
| 黒雨・サイバー刀 | 毒。5秒の専用継続ダメージ。不死系にも有効 |
| VOLT / RIOT バット | 半径2.5の衝撃波、周辺ダメージ25%、ノックバック1.0 |
| COIL / PILE ハンマー | 半径3.5の衝撃波、周辺ダメージ25%、ノックバック1.5 |

- 継続ダメージは1秒ごと2ダメージ（防御・無敵時間が適用される）。重ね掛けは累積せず残り時間を更新。炎と毒は同一対象では最後の効果を保持。
- 属性発動はプレイヤーごと12tick間隔。範囲効果は敵のみ、視線確認あり、最大12体。建物・家具を壊す爆発は使わない。ノックバック耐性は尊重する。
- 雷・炎・毒の斬撃粒子、電撃・火花・毒の追加粒子、衝撃波の同心円、属性ごとの効果音。状態・継続ダメージはサーバー管理。
- 行動停止は通常AIとNeonWardの独自行動の両方を停止。ボスの攻撃進行も短時間止める。
- 既存アイテムのデータは書き換えない。買い直し不要。説明欄に属性と2倍の説明を追加。
- テスト用サーバーで8武器の2倍ダメージ、通常武器の据え置き、衝撃波の副次ダメージとノックバック、スタン、ボスの短縮スタン、不死系への毒・炎の継続ダメージを確認。
- 実際のクライアントでの演出の見え方、実参加者による操作は未確認。
