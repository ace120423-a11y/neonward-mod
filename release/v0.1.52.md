# NeonWard v0.1.52

## VOLCANIC TOWER — 火山の戦闘塔・全30階
- 企業ビル内のギルドに火山専用の転送端末を追加。NIGHT SPIRE・FROST CITADELの端末と並び、火山の入口前へ移動できます。
- 各階は広い討伐エリア → 雑魚30体で岩扉開放 → ボス1体 → 撃破後に次階ゲート、の順で攻略します。30階突破後はギルドへ帰還。
- 雑魚は一度に最大6体。全30階を同時稼働させず、必要な階を分割生成します。誰もいない階は10秒後に残敵・ボス・攻撃演出を撤去します。
- 通常右クリックは保存した到達階から、しゃがみ右クリックは自分の記録を1階へ戻して再挑戦。同じ階にいる他プレイヤーの戦闘や突破記録はリセットしません。階の途中の討伐数は、退出後の再挑戦ではやり直しになります。
- 入口と各階の開始地点に帰還端末を設置。火山入口前からはスマホのファストトラベルも使用できます。

## 30体の専用ボス・火炎攻撃
- 甲虫・サソリ・大蛇・亀・溶鉱炉・鎖鐘・六翼の蛾・三頭猟犬など、体型を分けた30種類の専用モデルを追加。角や背中だけを付け替える共通モデルから作り直しました。
- 溜め・振り下ろし・突進・火炎放射・火球・溶岩弾の攻撃演出。火属性の攻撃には炎上による継続ダメージを付与。
- 23階は溶岩の投石巨人。岩を持ち上げる動き、投げる動き、目に見える飛翔弾、着弾、短時間の燃焼範囲を追加。
- 飛翔弾と燃焼範囲には上限と寿命を設定。ボス撃破時には即座に撤去し、ワールドに飛翔弾の残骸を保存しません。
- 新しい塔は既存2塔と別の進行記録を使用。古いボスの再読み込みによる重複を防止し、転送前には到着地点の足場も検査します。
